# 獨自升級系統 · TEN PATHS

這是一個免費、免登入、免 API、支援離線安裝的多職業 RPG 技能樹 App，使用繁體中文。

## 十大職業

機械工程師、作家、音樂家、動畫師、廚師、總裁／經營者、講師、運動家、修行者、命理研究者。每個職業有三條專精支線，每條四個階段，總共 120 個預設技能。

- **技能升級**：先完成指定實作，再按「完成一次修煉」，該技能直接 +1 LV，並依技能階級取得 35／55／80／120 XP；技能與等級無上限。
- **前置條件**：進階節點需要先將前置技能提升到指定等級；高階跨支線技能另需其他分支的能力。
- **階級稱號**：職業等級達 LV.1、3、6、10、16、25、40、60、100 時換更高階的職業稱號；LV.100 後每 50 級增加一次「超越轉生」。另有總體稱號、跨職業隱藏稱號及成就。
- **每日委託**：每天選出三項不同職業的練習方向。完成相關技能訓練後自動打勾。
- **自訂技能**：可新增技能、前置條件、能力描述和訓練目標。
- **資料存取**：自動儲存至目前瀏覽器 localStorage；可隨時匯出完整 JSON、在另一個裝置匯入。

> XP 屬於自我訓練紀錄，不是證照或能力測驗結果。請只在完成真實練習時按下升級。

## GitHub Pages 部署

1. 建立 GitHub Repository，例如 `ten-paths`。
2. 將 `index.html`、`manifest.webmanifest`、`sw.js`、`icon-192.png`、`icon-512.png` 全部放在 Repository **根目錄**。
3. Repository → **Settings** → **Pages** → **Build and deployment** → 選 `Deploy from a branch` → 分支 `main`、資料夾 `/(root)` → Save。
4. 開啟 GitHub 提供的 `https://你的帳號.github.io/ten-paths/`。
5. Android Chrome：右上角選單 → **安裝應用程式** 或 **新增至主畫面**。在 HTTPS 站台打開後，Service Worker 會快取檔案，以供離線使用。

## 本機直接使用

直接點開 `index.html` 即可用 Chrome、Edge 等瀏覽器操作技能樹，localStorage 支援情況取決於瀏覽器。為確保 PWA 安裝和離線功能，建議使用 GitHub Pages 等 HTTPS 網站。

## 備份與復原

「設定」→「匯出 JSON」取得紀錄備份。移到另一個裝置後在「設定」→「匯入 JSON」；**匯入會覆寫現有進度**。建議每週備份。`profession_catalog.json` 是可閱讀的原始職業與技能目錄，不是必備執行檔。
